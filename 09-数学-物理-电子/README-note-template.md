# 09-数学-物理-电子 笔记模板

适用范围：

- 数学
- 物理
- 电子

这个模板继承全仓规范，同时保留适合公式类、推导类、课程类笔记的强边界风格。

---

## 1. 文档头部模板

```md
# 标题

- [ ] 来源:
- [ ] 时间:
- [ ] 状态: 进行中 / 已完成 / 待复习
- [ ] 标签:

---

## 目录

- [Ch1 标题](#ch1-标题)
  - [1.1 知识点标题](#11-知识点标题)
  - [1.2 知识点标题](#12-知识点标题)
```

---

## 2. 章节模板

```md
## Ch1 标题

### Section Name 小节名

---

#### 1.1 Knowledge Point 知识点

> ◎ 核心：一句话说明这个知识点到底在讲什么。

##### ◇ 直觉理解

先讲人话，先讲图像，再讲公式。

##### ∎ 定义 / 公式

写定义、公式、定理或方程：

$$
...
$$

##### ✓ 结论

写这个知识点最后应记住的结论。

##### ⚠ 易错点

写容易混淆、容易算错、容易想反的地方。

##### ✦ 我的理解

写自己的话，说明这个知识点和前后内容的关系。

---
```

## 3. 符号约定

为了让阅读时一眼区分内容类型，统一使用下面这组符号：

- `◎ 核心`：一句话摘要
- `◇`：直觉、问题、前提、场景
- `∎`：定义、公式、推导
- `✓`：结论
- `⚠`：易错点、待核对
- `✦`：我的理解
- `✎`：备注

原则：

1. 不要频繁更换符号体系
2. 一篇文档内保持一致
3. 符号只做辅助，不替代标题层级

---

## 4. 使用建议

### 4.1 数学类

优先顺序：

- 直觉理解
- 定义 / 定理
- 推导 / 证明
- 例题
- 易错点

能用 LaTeX 表达就不要转成图片。

### 4.2 物理类

优先顺序：

- 对象 / 场景
- 基本规律
- 数学表达
- 图示
- 结论
- 易错点

### 4.3 电子类

优先顺序：

- 电路直觉
- 定义 / 公式
- 图示 / 电路图
- 结论
- 易错点
- 我的理解

## 5. 图和资源的最小约定

资源目录建议：

```text
assets\主题名\
├─ figures
└─ source
```

如果旧主题仍使用 `image/主题名/`，可以先沿用旧目录，但新资源命名应尽量规范。

推荐命名：

```text
[章节]-[主题]-[类型]-[序号].[扩展名]
```

例如：

- `01-basic-water-voltage-analogy-figure-01.svg`
- `02-rc-step-response-plot-01.svg`
- `03-opamp-inverting-amplifier-diagram-01.svg`

说明：

- 所有最终插入文档的图片统一放 `figures/`
- 图的类型通过文件名体现，不再通过目录进一步细分
- 默认输出为 `svg`，截图或仿真位图再使用 `png`

---

## 6. 最小执行规则

如果不想每次都写得很完整，至少保证：

1. 每个知识点使用单独的 `####` 标题
2. 每个知识点前加一条 `---`
3. 每个知识点写一条 `◎ 核心`
4. 公式与结论分开写
5. 易错点和待核对内容明确标出来

这样即使笔记还没写完，阅读时也不会混成一片。
