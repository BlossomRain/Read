# 09-数学-物理-电子 笔记模板

适用范围：数学、物理、电子。继承全仓 [README-notes-style.md](../README-notes-style.md)。

**课程类长笔记**（多章、多推导）请同时阅读 [电子/电子学/电子学一-笔记模板.md](电子/电子学/电子学一-笔记模板.md) 中的「正文 + 附录」与作图规范。

---

## 1. 文档头部

```md
# 标题

- [ ] 来源:
- [ ] 时间:
- [ ] 状态: 进行中 / 已完成 / 待复习
- [ ] 标签:

正文只保留结论与用法；长推导见文末 [附录](#附录)，文中以「见 [附录 X](#…)」引用。

---

## 目录

- [Ch1 …](#…)
  - [1.1 …](#…)
- [附录](#附录)
  - [A …](#附录-a-…)
- [下一章 / 分册](./主题第二章.md)   <!-- 多章时 -->
```

无附录的短笔记可删掉「正文/附录」说明行与目录中的附录项。

---

## 2. 章节层级

```text
## Ch1 / Chapter 1 …          # 章
### 1.x …                       # 大节
#### 1.x.y …                    # 小节（带编号 + 中英标题）
##### …                         # 小节内块（符号前缀）
```

---

## 3. 符号块（一篇文档内固定）

| 符号 | 用途 |
|------|------|
| `◎ 核心` | 小节开头一句话（引用块 `>`） |
| `◇` | 直觉、题目、场景、应用 |
| `∎` | 定义、公式、核心结论、求解 |
| `✓` | 结论或 **小结**（课程讲义体优先用「小结」收束） |
| `⚠` | 易错点 |
| `✎` | 备注（少用） |
| `✦ 我的理解` | 可选；与前后章关系紧时再写，避免每节重复 |

块之间用 `---` 分隔；不要为同一层内容混用多种符号。

---

## 4. 课程讲义体：小节骨架（推荐）

每个 `#### 1.x.y` 优先：

```md
#### 1.x.y Title 标题

> ◎ 核心：……

##### ∎ 核心结论
（1～3 句或关键式子；长推导写「见 [附录 X](#…)」）

---

##### ◇ 例题 / 应用
（数值题只保留条件 → 关键步 → 答案）

---

##### ✓ 小结

---
```

**不要**在正文重复展开已在附录写过的推导；**不要**把例题嵌在 `∎ 说明 / 推导` 中间。

---

## 5. 附录

放在主文档末尾、章间导航链接**之前**。

```md
## 附录

正文中的「见 [附录 X](#…)」均指本节。

### 附录 A 标题

**对应正文：** [1.2.1](#121-…)

（完整推导、证明、工具性数学……）

---
```

- 字母顺序 A、B、C…；标题简短、可检索
- 每条附录必须有「对应正文」回链
- 正文首次完整推导进附录，后文只引用字母

---

## 6. 数学 / 物理 / 电子 侧重点

| 类型 | 正文优先 | 附录优先 |
|------|----------|----------|
| 数学 | 定义、定理陈述、例题套路 | 证明、长计算 |
| 物理 | 规律、公式、图示直觉 | 从高斯/守恒出发的完整推导 |
| 电子 | 电路结论、Bode/相量结果、作图 | 求导、相量/复数基础、微分方程解 |

能用 LaTeX 写的不要截图；能一张图说清的不要拆成多张。

---

## 7. 图与资源

```text
image/主题名/          # 旧目录可沿用
  figures/             # 插入笔记的 svg/png
  source/              # tex、drawio、脚本
```

命名：`[章节]-[主题]-[diagram|plot|figure]-[序号].扩展名`  
引用：`![说明](./image/主题名/figures/01-basic-xxx-diagram-01.svg)`

TeX 图编译见 `电子学一-笔记模板.md` §6、§10。

---

## 8. 最小执行（赶时间时）

1. 头部元数据 + 目录（含附录项，若有）
2. 每小节一条 `◎ 核心`
3. 正文只写结论与用法；长推导丢附录并加链接
4. 资源命名与路径符合 §7
5. 同一篇文档内符号与「小结」用法一致
