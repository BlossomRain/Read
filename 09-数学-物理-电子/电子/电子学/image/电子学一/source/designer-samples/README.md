# Designer 代表图交稿目录

将 [CircuiTikZ Designer](https://circuit2tikz.tf.fau.de/designer/) 导出的代表图放在此处。

**绘制清单与命名规范：** 见 [`../figures/designer-sample-brief.md`](../figures/designer-sample-brief.md)

每个代表图建议提交：

- `sample-ch2-01-follower.json`（Save）
- `sample-ch2-01-follower.tex` 或 `.md`（Export CircuiTikZ code）

不必提交正式构建用的 `02-op-*.tex`；Agent 确认规范后会重写 `source/` 下对应文件。
